# Vite SPA Starter

A modern Single Page Application (SPA) boilerplate built with Vite and vanilla JavaScript.

## Features

- ⚡️ Lightning fast development with Vite
- 🔥 Hot Module Replacement (HMR)
- 📦 Optimized build process
- 🎯 Modern ES6+ JavaScript support
- 🎨 CSS preprocessing support
- 📱 Development server with instant reload

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/adibenshalom/vite-spa-starter.git
   cd vite-spa-starter
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```

## Project Structure

```
vite-spa-starter/
├── public/           # Static assets
├── src/             # Source files
│   ├── style.css    # Main styles
│   ├── main.js      # Entry point
│   └── counter.js   # Example module
├── index.html       # HTML template
├── package.json     # Dependencies and scripts
└── vite.config.js   # Vite configuration
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## Customization

This boilerplate provides a minimal setup to get you started. You can:

- Add TypeScript support
- Integrate CSS frameworks (Tailwind, Bootstrap, etc.)
- Add state management (Redux, Zustand, etc.)
- Include routing (React Router, Vue Router, etc.)
- Set up testing frameworks (Vitest, Jest, etc.)
